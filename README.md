🐍 Python Beginner Toolkit

Welcome to Python Beginner Toolkit! 🎉

This repository contains a collection of small, beginner-friendly Python projects created to practice and strengthen fundamental Python programming concepts.

Instead of building one large application, this repository brings together multiple mini projects that demonstrate different programming concepts through simple and practical examples.

---

📌 Projects Included

🔢 1. Number Tools

File: "number_tools.py"

Number Tools is a simple program that performs several operations on a number entered by the user.

Features:

- Checks whether a number is Even or Odd
- Checks whether a number is Prime
- Calculates the Square
- Calculates the Cube
- Calculates the Factorial

Concepts Practiced:

- Variables
- User input
- "if-else" conditions
- "for" loops
- Arithmetic operators
- Type conversion

---

🔤 2. Text Analyzer

File: "text_analyzer.py"

Text Analyzer allows the user to enter a piece of text and analyzes it using basic Python string operations.

Features:

- Counts the number of words
- Counts characters
- Counts vowels
- Counts sentences

Concepts Practiced:

- Strings
- String methods
- Lists
- Loops
- Conditions
- User input

---

💰 3. Bill Splitter

File: "bill_splitter.py"

Bill Splitter is a simple utility that calculates how much each person should pay when sharing a bill.

The user enters the total bill, number of people, and tip percentage.

Features:

- Calculates the tip amount
- Calculates the total bill
- Splits the bill between multiple people
- Displays the amount each person needs to pay

Concepts Practiced:

- Variables
- User input
- Floating-point numbers
- Arithmetic calculations
- Type conversion
- Basic formatting

---

🧠 4. Quiz Game

File: "quiz_game.py"

Quiz Game is a simple multiple-choice Python quiz.

The program displays questions with multiple options and checks the user's answers.

Features:

- Multiple-choice questions
- Automatic answer checking
- Score tracking
- Final score display
- Different messages based on the final score

Concepts Practiced:

- Lists
- Dictionaries
- Loops
- Conditions
- Functions and user input
- Score calculation

▶️ How to Run the Projects

2. Open the project folder

cd python-beginner-toolkit

3. Run any project

Or:

python text_analyzer.py

python bill_splitter.py

python quiz_game.py
